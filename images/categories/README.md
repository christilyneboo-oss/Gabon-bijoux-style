# Images des categories

Ajoute ici tes images de premiere vue avec ces noms exacts :

- `ensembles.jpg`
- `bracelets.jpg`
- `boucles.jpg`
- `bagues.jpg`
- `colliers.jpg`
- `chevilleres.jpg`

Les formats `.jpg`, `.jpeg`, `.png` et `.webp` sont acceptes, mais le CSS utilise actuellement l'extension `.jpg`.
Pour utiliser un autre format, adapte simplement le nom dans `css/style.css`.

Conseils : images horizontales ou carrees, bonne lumiere, sujet bien visible, environ 1200 px de large.
